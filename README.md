# News Publishing Platform

## Overview

A modern news publishing platform that allows administrators, editors, and writers to manage and publish local, global, and sports news efficiently through a responsive dashboard.

---

## The Problem

Many news websites face difficulties in organizing articles and managing publishing permissions between writers, editors, and administrators.

This often leads to:

* Slow publishing workflow
* Poor article organization
* Difficulty managing user permissions
* Weak content management

---

## The Solution

I developed a complete news management platform with role-based access control to simplify publishing operations and improve content organization.

The platform allows:

* Writers to create articles
* Editors to review and manage content
* Administrators to control the entire system

---

## Main Features

* News publishing system
* Local, global, and sports categories
* Admin, editor, and writer roles
* Dashboard management
* Authentication system
* Responsive design
* Article management (CRUD)
* Image upload support

---

## Technologies Used

* HTML
* CSS
* Bootstrap
* PHP Laravel
* MySQL

---

## Results

The platform helps manage news content efficiently and improves collaboration between administrators, editors, and writers through an organized workflow.
